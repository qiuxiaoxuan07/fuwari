随着 Minecraft 的不断更新，越来越多的玩家倾向于拥有一个属于自己和好友的专属服务器。然而，命令行开服对新手不够友好，频繁的后台重启与文件管理也显得繁琐。

**MCSManager (简称 MCSM)** 是一款开源、分布式、轻量级的网页端 Minecraft 服务端管理面板。它不仅支持控制台实时交互，还提供了简便的实例管理、计划任务（如自动备份、重启）以及多节点管理。

本文将带你从零开始，一步步在 Linux 或 Windows 上安装 MCSM 并成功运行你的 Minecraft 服务器。

---

### 一、 准备工作

在搭建服务器之前，我们需要搞定两件事：**选择运行环境**与**安装 Java (JDK)**。

#### 1. 运行环境选择
- **云服务器 (Linux 推荐)**：如腾讯云、阿里云等。系统推荐选择 **Ubuntu 20.04/22.04 LTS** 或 **Debian 11/12**。Linux 占用系统资源少，非常适合作为 24 小时运行的服务器。
- **家用电脑 (Windows)**：如果你只想和三两好友开黑，且电脑配置尚可、能够长时间不关机，也可以直接在 Windows 本地开服。

#### 2. Java 版本选择
Minecraft 不同的版本对 Java (JDK) 的版本有严格的要求。请根据你计划运行的服务端版本选择：

| Minecraft 服务端版本 | 推荐 Zulu JDK 版本 |
| :--- | :--- |
| **1.7.10 - 1.12.2** | Zulu JDK 8 |
| **1.16.5** | Zulu JDK 11 |
| **1.17 - 1.17.1** | Zulu JDK 16 |
| **1.18 - 1.20.4** | Zulu JDK 17 |
| **1.20.5 及以上 (如 1.21)** | Zulu JDK 21 |

> **提示**：目前强烈建议安装 **Azul Zulu JDK**（一款针对多平台深度优化的 OpenJDK 发行版，对 Minecraft 的运行效率和兼容性极佳）。如果你是 Linux 系统，可以使用官方源或包管理器进行安装，或者使用 MCSM 后面板内置的 Java 自动安装功能。

---

### 二、 安装 MCSManager

MCSManager 采用 **Web 面板 (Panel)** + **守护进程 (Daemon)** 的分布式架构。对于单机开服，我们直接在同一台机器上把两个部分都装好即可。

#### 1. Linux 一键安装 (推荐)
打开终端，执行以下官方提供的一键安装脚本：

```bash
# 中文地区推荐使用 Gitee 镜像源一键安装
wget -qO- https://gitee.com/mcsmanager/script/raw/master/setup_cn.sh | bash
```

如果连接 GitHub 更顺畅，可以使用 GitHub 镜像：
```bash
wget -qO- https://github.com/MCSManager/MCSManager/raw/master/release/setup.sh | bash
```

安装完成后，终端会输出面板的默认端口和启动状态。通常情况下：
- **Web 面板地址**：`http://你的服务器IP:23333`
- **默认管理员账号**：`admin`
- **默认管理员密码**：`123456` *(登录后请务必在第一时间修改密码！)*

**管理服务命令**：
```bash
systemctl start mcsm-web     # 启动 Web 服务
systemctl start mcsm-daemon  # 启动守护进程服务
systemctl enable mcsm-web    # 设置开机自启
systemctl enable mcsm-daemon # 设置开机自启
```

#### 2. Windows 安装方式
1. 访问 [MCSManager 官网](https://mcsmanager.com/) 或其 GitHub Release 页面，下载最新的 Windows 版压缩包（通常命名为 `MCSManager-vX.X.X_Win_x64.zip`）。
2. 将压缩包解压到一个不包含中文或空格的路径下（例如 `D:\mcsm`）。
3. 双击运行目录下的 `启动 Web 面板.bat` 和 `启动守护进程.bat`。
4. 保持弹出的命令行窗口不要关闭，使用浏览器访问 `http://localhost:23333` 即可登录。

---

### 三、 登录面板并创建服务器

#### 第一步：登录与基本配置
1. 打开浏览器输入 `http://你的服务器IP:23333`。
2. 输入默认账号密码（`admin` / `123456`）进行登录，并按提示修改管理员密码。

#### 第二步：创建服务器实例
1. 在左侧菜单栏点击 **「应用实例」**，然后点击 **「新建实例」**。
2. 选择 **「Minecraft 游戏服务端」** -> **「Java 版游戏服务器」**（如果是手机版请选择基岩版）。
3. 选择 **「快速起步（引导创建）」** 或 **「自定义创建」**：
   - **快速起步**：你可以直接从官方推荐列表中选择常用的服务端核心（如 Paper, Purpur, Forge）和版本，面板会自动帮你下载并创建实例。
   - **自定义创建**：如果你已经自己准备好了 `.jar` 服务端文件，可以上传到服务器中，然后在这里指定它的路径。
4. 输入你的服务器名称，例如 `My Minecraft Server`。

#### 第三步：配置启动参数
1. **Java 路径**：在实例设置中，找到 Java 路径。如果面板自动识别到了你之前安装的 Java，可以直接选择。如果没找到，可以手动指定 `java` 或 `java.exe` 的绝对路径。
2. **内存分配**：
   - **最小内存**（初始化内存）建议不要设成和最大内存一样大，避免服务器一启动就过度占用整机物理内存。通常最小内存分配 `1G` (1024M) 即可。
   - **最大内存**根据版本与玩家数进行分配：一般 1.20+ 的原版/轻量联机分配 `4G` (4096M) 内存，如果是中大型 Mod 服，建议分配 `8G` 以上。
3. **启动指令**：一般面板会自动生成，格式类似于 `java -Xms1024M -Xmx4096M -jar server.jar nogui`。

#### 第四步：接受 EULA 协议并首次启动
1. 点击 **「开启实例」**。
2. 首次启动通常会瞬间停止，并在控制台显示 `You need to agree to the EULA`。
3. 返回实例管理，进入 **「特定配置」** -> **「Eula 配置文件」**，将协议改为 `true`（或者在文件管理中打开 `eula.txt` 修改为 `eula=true`）。
4. 再次点击 **「开启实例」**，你将在控制台中看到世界生成进度，当显示 `Done (xxx s)! For help, type "help"` 时，代表服务器已成功开启！

### 四、 网络配置与外网联机

服务器开好后，如何让朋友们连进来呢？这取决于你的网络环境：

#### 1. 云服务器 (公网 IP)
如果你的服务器在阿里云、腾讯云上，你只需要在云服务商的后台配置**安全组（Firewall / Security Group）**：
- **Minecraft 默认联机端口**：放行 `25565`（协议：TCP）。
- **MCSM 面板端口**：放行 `23333`（TCP，用于浏览器访问 Web 页面）与 `24444`（TCP/UDP，用于节点通信，如果是一机开服仅需放行 Web 端口）。

玩家在游戏中添加服务器，输入 `服务器公网IP:25565` 即可连入。

#### 2. 家用电脑开服 (无公网 IP)
如果服务器开在自家电脑上，外网玩家是无法直接连接你的局域网 IP 的。你有以下两个解决方案：
- **方案 A (有宽带公网IP)**：去路由器后台配置 **DMZ 主机** 或 **端口映射 (Port Forwarding)**，将本地电脑的 `25565` 映射到外网，配合 DDNS（动态域名解析）食用更佳。
- **方案 B (无公网IP，最常用)**：使用内网穿透工具。例如：
  - **Sakura Frp (樱花穿透)**、**ChmlFrp** 等公共穿透服务。
  - 自己买一台便宜的云服务器，使用 **FRP** 搭建专属内网穿透。
  - 将穿透工具的本地端口设置为 `25565`，然后将穿透服务商分配给你的公网域名和端口发给玩家即可。

### 五、 进阶配置与优化建议

#### 1. 关闭正版验证 (非正版玩家需要)
如果联机的好友中有人使用的是非官方启动器，可能会遇到 `Failed to verify username!`（无效的会话/未经验证的用户名）错误。
- **解决方法**：在 MCSM 实例的 **「文件管理」** 中，打开 `server.properties` 文件。
- 找到 `online-mode` 行，将值由 `true` 改为 `false`。
- 保存文件并重启服务器。

> *注：关闭正版验证后，建议在服务器中安装注册登录插件（如 AuthMe Reloaded），以防止玩家随意冒用他人的游戏 ID。*

#### 2. 自动备份任务
游戏数据无价。你可以利用 MCSM 自带的计划任务来实现定时自动备份。
1. 在左侧菜单点击 **「计划任务」** -> **「新建计划任务」**。
2. 任务类型选择 **「发送控制台指令」** 或 **「备份实例文件」**。
3. 设定每天凌晨（例如 04:00）自动发送指令 `/save-all`，接着在 5 分钟后执行备份实例任务。
4. 这样即使服务器意外崩坏或者遭遇玩家恶意破坏，也可以随时一键恢复到之前的状态。

#### 3. 性能优化推荐
原版 Minecraft 服务端（Vanilla）由于缺乏多线程优化，往往容易卡顿。强烈建议使用以下第三方优化服务端：
- **PaperMC**：最经典的优化端，完美兼容 Bukkit/Spigot 插件，性能远胜原版。
- **Purpur**：在 Paper 基础上增加了极多自定义配置项。
- **Fabric**：装配高性能优化模组（如 Lithium、Krypton、FerriteCore）的绝佳选择，适合模组服。
